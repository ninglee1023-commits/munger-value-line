# 每日芒格式 Value Line

這是一個中文優先、純靜態的公司研究網站，將每日 Value Line 研究整理成可搜尋的網頁文章，不再以失效或不存在的 PDF 作為主要閱讀入口。

## 內容

- 首頁研究索引：公司、代碼、日期、行業、核心結論與估值判斷
- 本地搜尋與行業篩選，無需後端
- 公司文章頁：長期數據圖表、商業模式與護城河、單位經濟、利潤增長拆解、資本配置、同行比較、估值、芒格式結論、追蹤指標、來源鏈接
- 目前收錄：騰訊、華住、招商銀行、攜程、台積電、美的、京東、順豐、百勝中國、貴州茅台

## GitHub Pages

網站輸出在 `dist/`，可直接把此 repo 的 `main` 分支、`/ (root)` 設為 GitHub Pages 的來源。網站不依賴 Node、後端或外部 CDN。

日後每天新增研究時，主要更新 `dist/app.js` 的 `STUDIES` 陣列，為新公司加入文章欄位、圖表數列和來源鏈接即可。

## 研究口徑

數字與結論沿用每日研究整理時點；圖表是方向性視圖，不取代原始披露。市場價格、估值和季度數據會變，使用前應點開文章底部的公司／交易所來源重新核對。

本網站內容僅供研究整理，不構成投資建議。
