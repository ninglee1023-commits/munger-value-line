# 每日芒格式 Value Line

中文優先、純靜態的上市公司研究網站。每期研究直接做成可閱讀、可搜尋、可追溯來源的網頁文章，不再把 PDF 當作主要入口。

## 網站內容

- 首頁顯示公司、代碼、研究日期、行業、核心結論與估值判斷，可全文搜尋及按行業篩選。
- 每家公司固定提供 4 張數據圖、長期財務表、商業模式與護城河、單位經濟、利潤拆解、資本配置、同行比較、估值、反證、3–5 個追蹤指標及來源台帳。
- 目前收錄：騰訊、華住、招商銀行、攜程、台積電、美的、京東、順豐、百勝中國、貴州茅台。
- 文章正文保留完整研究深度；圖表只使用文中已核對數字，並標明年度／季度與單位差異。

## 技術與部署

網站只有 HTML、CSS、JavaScript 和 JSON，不需要 Node、資料庫、後端或外部 CDN。GitHub Pages 使用 `main` 分支的 `/ (root)` 發布；推送後可在 Actions 的 `pages-build-deployment` 工作流程檢查部署狀態。

主要檔案：

- `index.html`：網站外殼與基本資訊。
- `styles.css`：桌面及手機版排版。
- `app.js`：首頁索引、搜尋篩選、圖表和文章生成器。
- `<公司代號>.json`：每家公司一份完整研究資料，例如 `tencent.json`。
- `dist/`：與根目錄同步的可部署／預覽副本。

## 每天新增一篇

1. 完成研究並核對公司、交易所及監管原始資料。
2. 複製一份現有公司 JSON，填入完整正文、長期數據表、結論、追蹤指標及來源；不要只貼摘要。
3. 在 `app.js` 的 `CATALOG` 新增公司卡片、研究日期、估值判斷、4 組圖表及 JSON 檔名。
4. 本地打開首頁，驗證搜尋、桌面／手機排版、全部圖表、表格和來源連結。
5. 同步 `dist/`，提交至 `main`，待 GitHub Pages 部署成功後再把網站連結視為已發布。

每日 Codex 任務已按這個格式銜接：新研究要先寫成完整網頁資料，再更新目錄與圖表；若 GitHub 寫入需要批准，任務會停在發布前請使用者確認，不會把尚未上線的內容說成已發布。

## 研究口徑

文章日期代表研究時點，不代表今日報價。估值、季度數字及行業比較可能隨新披露改變，閱讀時應使用文章底部的原始資料入口重新核對。

本網站內容僅供研究整理，不構成投資建議。
