# 每日芒格式 Value Line

中文、纯静态的长期基本面研究网站。网页全文为主要入口；自2026-09-19起从「每日芒格式公司研究」同步完整原报告。后续自动流程直接同步全文到网页，不再生成或检查新 PDF；现有 PDF 和下载入口保留。既有报告取得对应原稿后再逐篇更新，来源见各篇。

## 原报告同步

研究由芒格来源任务产出，网站承接全文和发布。不得用另一份提示词重新生成、用摘要扩写，或为了网页结构删改原报告。新同步报告使用 `format: "markdown"`，原文完整保存在 `markdown`；旧的结构化报告继续正常显示，章节和图表数量不再固定为 17 章、4 图。

`source` 仅保存公开的来源标题、原研究日期、同步时间、原文 SHA-256及可选图片目录 `assetBase`。网页分别显示原研究日期与同步时间；私有任务／消息标识和去重台账保存在网站仓库之外。新同步稿不需要 `pdf` 字段即可验证及发布；已有 `pdf: {url, label}` 继续显示下载入口，并仅在该字段存在时验证链接或本地文件。完整交接字段、去重及发布步骤见 [SYNC_WORKFLOW.md](SYNC_WORKFLOW.md)。

重整采用Munger/Buffett/Value Line框架：长期经营记录、周期正常化、每100元单位经济、财务验证护城河、增量ROIC、Owner Earnings和每股价值。好生意与好价格分别判断。银行、受监管基建、租赁密集服务业采用相应口径，不机械套工业FCF。

## 数据边界

- 财务数字标明币种、期间、GAAP/调整口径；估值参数显式标注为假设。
- 旧来源保留原日期，不冒称所有历史资料均在本次逐页重读。最新重点变动重新查核。
- **未完成全部公司所有字段的连续10—15年提取**。历史锚点、逐年完整序列分别标识；缺失不是零，也不等于公司没有披露。
- 维护/增长CapEx、项目级增量ROIC、部分同行同口径数据、复权长期总回报仍存在缺口。全文设覆盖矩阵，不虚构精确数值。
- 行情为注明日期的快照，不是实时价；无法核验同日股价、汇率和股数时不作当前低估结论。
- 信息仅供研究学习，不构成投资建议。

## 文件与更新

index.html为外壳；styles.css为响应式样式；app.js为目录、图表和正文渲染；每家独立JSON保存全文。research-history.json同时保留原研究日和本次修订日，用于30天去重。

本次可复现的批量重整：revision-data.cjs与editorial-additions.cjs保存编辑内容，rebuild.cjs从固定基线81c2421生成新版本。运行后再执行normalize-chinese.ps1统一简体。它是本次迁移构建，不应在新增日更之后直接重跑覆盖新文章。

qa.cjs按实际目录和报告格式检查文章、引用ID、图表、来源元数据、原文SHA-256及桌面/手机页面；本地检查额外使用不写入网站、标为原稿同步且不带PDF的Markdown测试报告，验证20个章节、表格及没有虚构下载入口。已有PDF入口仍按实际字段检查。浏览器依赖通过环境变量RESEARCH_NODE_MODULES指定；不是网站运行依赖。运行node qa.cjs自动启动临时本地预览，或传入线上网址进行发布后验证；线上检查同时逐篇比对JSON与本地待发布版本。截图和结果存放于不发布的.qa目录。受限环境应将TEMP和TMP指向可写的临时目录。

GitHub Pages使用main分支根目录，没有dist副本，也没有数据库或外部前端CDN。每次完成研究后依用户授权提交、推送，再检查实际线上JSON版本和全文；未验证上线不得称已发布。既有发布授权无需逐次重复询问，权限或部署失败则明确报告。
